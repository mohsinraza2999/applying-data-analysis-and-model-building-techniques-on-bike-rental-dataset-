# applying-data-analysis-and-model-building-techniques-on-bike-rental-dataset-
<p>For this purpose we used Seoul dataset. Seoul is a company offers various bike rental options for tourists and residents. Seoul Public Bike, is an unmanned rental system that can be used anywhere, anytime by anyone, designed to address traffic congestion, air pollution, and high oil prices in Seoul, enhancing the quality of life for citizens.</p>

<p>
  This project provides a complete end-to-end analysis of a bike rental dataset using Python. The goal is to understand the key factors that influence bike rental demand and build predictive models to forecast future usage.
</p>

<hr/>

<h2>📁 Project Structure</h2>

<ul>
  <li><strong>📊 Exploratory Data Analysis (EDA):</strong> Visual and statistical exploration of the dataset</li>
  <li><strong>🧹 Data Preprocessing:</strong> Handling missing values, feature engineering, and encoding</li>
  <li><strong>📈 Feature Selection:</strong> Identifying key predictors using correlation and importance plots</li>
  <li><strong>🤖 Modeling:</strong> Training and evaluating multiple regression models (Linear Regression, Random Forest, etc.)</li>
  <li><strong>📉 Model Evaluation:</strong> Comparing models using RMSE, MAE, and R² scores</li>
</ul>
